条款重排校稿台

粘贴“编号|正文”导入 · 重排 / 合并 / 拆分 / 删除后引用始终绑定原条款 · 修复全部失效引用后才能下载

导入

每行一条，格式为 编号|正文，编号从 1 连续排列，共 2～40 行； 正文用 [[编号]] 显式引用其他条款（如 [[3]]，编号两侧不可有空格）。 任何格式错误、编号重复或引用无目标都会导致整份拒收。

如之前点过「保存存档」，可点「恢复存档」直接恢复基线、顺序、正文与身份上界，继续校订。

    原稿对照

    基线为本次成功导入时的原稿，导入后不可改变；仅列按稳定身份识别出的发生变化的条款： 新增 / 删除 / 正文改动 / 移动（标签可并存）。正文按引用绑定比较，仅显示编号变化不算改动； 移动只计仍存在条款间先后关系的颠倒，删除或拆分插入造成的编号平移不算移动。 现存条款按当前顺序排列，删除条款随后按原顺序排列。对照始终基于已保存草稿： 取消编辑或保存失败不改变对照；预览刷新失败时仍按已提交草稿对照。

    勾选条款摘录

    收录勾选条款及其直接、间接引用的全部现存条款（自引用、循环与重复引用只收录一次）； 摘录按草稿当前顺序从 1 连续编号，正文中的引用已改用摘录内编号，其余字符不变。 收录范围内存在失效引用时整份拒绝；范围外的失效引用不影响摘录，也不解除整稿「下载纯文本」的限制。 摘录为只读操作，不改变草稿、原稿基线、身份上界与引用绑定；改稿、切换勾选或重新导入会立即清空结果。

    条款列表

    用 ↑↓ 或拖拽 ⠿ 调整顺序；勾选两条不同条款后点「合并所选」可按当前显示顺序合并；勾选一条或多条后点「复制所选」可在所选最后一条之后生成整组可独立编辑的副本；点「拆分」可在选定分界处把一条已保存正文拆成前后两条（原指向本条的引用可选落前段或后段）；编号为当前显示编号，引用始终指向导入时绑定的条款。
